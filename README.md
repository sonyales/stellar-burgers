# Stellar Burgers

**Stellar Burgers** — SPA космической бургерной. В приложении можно собрать бургер из ингредиентов, оформить заказ, посмотреть общую ленту заказов и управлять данными профиля.

Проект реализован на React и TypeScript. Для управления состоянием используется Redux Toolkit, для маршрутизации — React Router, для работы с сервером — REST API.

## Функциональность

### Конструктор бургеров

* загрузка ингредиентов с сервера;
* отображение ингредиентов по категориям;
* добавление булки и ингредиентов в конструктор;
* подсчёт итоговой стоимости заказа;
* оформление заказа для авторизованных пользователей;
* отображение номера созданного заказа после успешного оформления.

### Авторизация

* регистрация пользователя;
* вход в аккаунт;
* выход из аккаунта;
* восстановление и сброс пароля;
* получение данных текущего пользователя;
* обновление данных профиля;
* защита приватных маршрутов;
* перенаправление неавторизованных пользователей на страницу входа.

### Профиль пользователя

* отображение данных пользователя в форме профиля;
* редактирование имени, email и пароля;
* сохранение изменений через API;
* отмена изменений с возвратом формы к исходным значениям;
* просмотр истории заказов пользователя.

### Лента заказов

* общая лента заказов доступна всем пользователям;
* история заказов пользователя доступна только после авторизации;
* для заказов отображаются ингредиенты, статус и итоговая стоимость;
* детальная информация о заказе открывается в модальном окне;
* прямой переход по URL открывает отдельную страницу заказа.

## Реализация

### Глобальное состояние

Состояние приложения хранится в Redux store и разделено на функциональные слайсы:

* `burgerIngredients` — список ингредиентов;
* `burgerConstructor` — состояние конструктора бургера;
* `createOrder` — оформление заказа;
* `publicOrders` — общая лента заказов;
* `userOrders` — заказы пользователя;
* `userData` — данные пользователя и авторизация;
* `passwordRecovery` — восстановление пароля;
* `orderInfo` — получение заказа по номеру.

Для работы с Redux используются типизированные версии `useDispatch` и `useSelector`. Асинхронные запросы вынесены в `createAsyncThunk`, а компоненты получают данные через селекторы.

### Работа с API

Приложение взаимодействует с REST API для получения ингредиентов, регистрации, авторизации, восстановления пароля, обновления профиля, оформления заказа, получения общей ленты заказов и истории заказов пользователя.

Для авторизованных запросов используется access token. Если access token истёк, выполняется обновление через refresh token, после чего исходный запрос повторяется.

### Роутинг

Маршрутизация реализована через React Router. В приложении есть публичные маршруты, приватные маршруты и маршруты, доступные только неавторизованным пользователям.

Приватные маршруты защищают профиль пользователя, историю заказов и оформление заказа. Если пользователь не авторизован, он перенаправляется на страницу входа.

### Модальные окна через роутинг

Модальные окна ингредиентов и заказов связаны с URL. При переходе из интерфейса карточка открывается поверх текущей страницы, а при прямом открытии ссылки отображается как отдельная страница.

Такой подход используется для:

* страницы ингредиента;
* заказа из общей ленты;
* заказа из истории пользователя.

### Стилизация

Для стилизации используются глобальные CSS-стили и CSS Modules. Компонентные стили изолированы через `.module.css`.

## Маршруты

| Маршрут                   | Доступ                        | Описание                                     |
| ------------------------- | ----------------------------- | -------------------------------------------- |
| `/`                       | Все пользователи              | Конструктор бургеров                         |
| `/feed`                   | Все пользователи              | Общая лента заказов                          |
| `/feed/:number`           | Все пользователи              | Детальная информация о заказе из общей ленты |
| `/ingredients/:id`        | Все пользователи              | Детальная информация об ингредиенте          |
| `/login`                  | Неавторизованные пользователи | Вход в аккаунт                               |
| `/register`               | Неавторизованные пользователи | Регистрация                                  |
| `/forgot-password`        | Неавторизованные пользователи | Восстановление пароля                        |
| `/reset-password`         | Неавторизованные пользователи | Сброс пароля                                 |
| `/profile`                | Авторизованные пользователи   | Профиль пользователя                         |
| `/profile/orders`         | Авторизованные пользователи   | История заказов пользователя                 |
| `/profile/orders/:number` | Авторизованные пользователи   | Детальная информация о заказе пользователя   |

## Переменные окружения

Для работы с API необходимо создать файл `.env` в корне проекта и добавить переменную:

```env
BURGER_API_URL=https://norma.education-services.ru/api
```

Пример находится в файле `.env.example`.

## Запуск проекта

### Клонировать репозиторий

```bash
git clone https://github.com/sonyales/stellar-burgers.git
cd stellar-burgers
```

### Установить зависимости

```bash
npm install
```

### Создать файл окружения

```bash
cp .env.example .env
```

### Запустить приложение

```bash
npm start
```

После запуска приложение откроется в браузере. По умолчанию dev server работает на порту `4000`.

## Тестирование

В проекте настроены unit- и e2e-тесты.

* **Jest** используется для проверки Redux store и слайсов.
* **Cypress** используется для e2e-сценариев конструктора: добавление ингредиентов, открытие и закрытие модальных окон, оформление заказа.
* **Storybook** используется для изолированного просмотра UI-компонентов.
